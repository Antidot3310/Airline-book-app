# Авиакасса — Настольная система бронирования и продажи авиабилетов

Данный монорепозиторий содержит исходный код настольного приложения «Авиакасса» на платформе C# (.NET). Приложение автоматизирует процесс продажи, бронирования, оплаты и возврата авиабилетов для трёх ключевых ролей: Пассажира, Кассира и Администратора, а также включает встроенный служебный модуль «Эмулятор».

### Принципы взаимодействия подсистем

1. **Изоляция представления:**
   * `/backend` компилируется в библиотеку классов (`Class Library`), инкапсулирует всю бизнес-логику (M1–M15), доменные модели и контекст Entity Framework Core (SQLite). Он не зависит от интерфейса пользователя и графических библиотек.
   * `/frontend` — исполняемый проект Windows Desktop (WPF или WinForms), отвечающий исключительно за визуализацию окон и взаимодействие с пользователем.
2. **Контракт через C#-интерфейсы:**
   * UI не обращается к БД напрямую. Взаимодействие происходит через строго типизированные интерфейсы сервисов ядра (`IFlightService`, `IBookingService`, `IPaymentService`, `IRefundService`, `IVirtualClockService` и др.) с использованием Dependency Injection (`Microsoft.Extensions.DependencyInjection`).
3. **Единый источник времени:**
   * Текущее время во всех модулях и окнах получается исключительно из сервиса виртуального времени `IVirtualClockService` (M12).
4. **Хранение данных:**
   * Реляционная база данных SQLite (`airline.db`).
